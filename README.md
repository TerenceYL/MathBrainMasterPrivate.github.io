# 隱私權政策

**生效日期：** 2025 年 11 月 21 日

本應用程式（以下簡稱「本 數學大腦練習/速算 (Math Brain Practies/Master) App」）由 鈦錀鍶, TerenceBSPlayer 開發與維護。

本政策旨在向所有使用者，特別是家長們，明確說明本 App 的資料處理方式。

## 1. 我們不收集任何個人資訊

本 App 的核心宗旨是提供一個安全的平台，提供軟體程式給使用者，同時確保用戶隱私。

**我們特此聲明，本 App 不會從使用者（包括但不限於父母與孩童）收集任何個人識別資訊 (Personally Identifiable Information, PII)，也不會收集任何非個人識別資訊、設備資訊、位置資訊或使用行為數據。**

這表示：
* 您在 App 內輸入的任何資料，僅會儲存在您的設備本地，不會上傳至任何伺服器，也不會與我們或任何第三方分享。
* 本 App 不會透過任何方式追蹤您的設備或使用習慣。
* 本 App 不會使用任何第三方分析工具或廣告 SDK。

## 2. 兒童隱私

本 App 提供 13 歲以下孩童使用，因此我們對兒童隱私保護極為重視。

**由於本 App 不收集任何使用者資料，包括來自兒童的資料，因此我們自動符合並超越了大多數兒童線上隱私保護法規（例如《兒童線上隱私保護法》(COPPA)）的要求，因為我們根本不收集資料。**

家長們可以完全放心，您的孩子在使用本 App 時，其任何數據都只存在於您的設備中，不會被傳輸、儲存或分享到外部。

## 3. 資料安全

所有您在 App 中輸入的數據都安全地儲存於您的本地設備上。本 App 不具備資料上傳或傳輸功能，從而最大程度地降低了數據洩露的風險。

## 4. 政策變更

我們可能會對本隱私權政策進行變更，在此情況下，我們會在此類變更生效前，透過本服務發佈更新後的政策或根據適用法律以其他方式通知您。本隱私政策的任何變更將在此類變更通知中規定的合理期間之後生效。
